# PokeDex Builder
 
Односторінковий застосунок на Vue 3 + TypeScript: перегляд покемонів
з реального PokeAPI, сторінка деталей і збір власної команди з 6 покемонів.
 
## Живе демо
[pokedex-app.vercel.app](посилання зʼявиться після Кроку 5)
 
## Технології
- Vue 3 (Composition API)
- TypeScript
- Vue Router
- Pinia
- PokeAPI
 
## Функції
- список покемонів з реального API з обробкою завантаження і помилок
- сторінка деталей: типи, характеристики, зріст, вага, здібності
- команда з 6 покемонів зі збереженням у localStorage
 
## Запуск локально
```
npm install
npm run dev
```
